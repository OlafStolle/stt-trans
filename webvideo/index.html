Tab-Recorder

Nimmt einen Edge-Tab auf — Video+Audio oder nur Audio.

  1. Button drücken.
  2. Im Dialog „Chromium-Registerkarte" wählen, Edge-Tab anklicken.
  3. Checkbox „Registerkartenaudio freigeben" anhaken.
  4. „Teilen" drücken → Aufnahme läuft.
  5. „Stopp" klicken → Download-Link erscheint.
